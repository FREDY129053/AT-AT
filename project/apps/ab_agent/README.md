# 🖥️ UI & A/B Testing Module

Подсистема агентного тестирования пользовательских интерфейсов с поддержкой моделирования поведения пользователей, UX-аналитики и A/B-экспериментов.

Модуль позволяет запускать множество виртуальных пользователей, взаимодействующих с веб-приложением через браузер, и получать количественные и качественные данные о поведении пользователей.

---

## ✨ Возможности

* Автоматическая генерация пользовательских агентов
* Создание персон (Personas)
* Выполнение пользовательских сценариев через браузер
* Имитация реального поведения пользователей
* Массовый запуск агентов
* A/B тестирование интерфейсов
* Сбор UX-метрик
* Сбор пользовательских событий
* Формирование аналитических отчетов
* Расчет статистической значимости результатов

---

## 🧠 Концепция

В отличие от классических A/B-платформ, использующих только реальных пользователей, система позволяет проводить предварительную проверку интерфейсов при помощи LLM-агентов.

Каждый агент представляет собой виртуального пользователя со своим:

* опытом использования продукта;
* уровнем подготовки;
* целью посещения сайта;
* поведенческим профилем.

Агенты самостоятельно взаимодействуют с интерфейсом и выполняют поставленные задачи, что позволяет проводить UX-исследования до появления реального трафика.

---

## 🤖 UXAgent

В основе агентного тестирования лежит подход, аналогичный фреймворку UXAgent, использующему LLM-агентов для проведения usability-тестирования веб-интерфейсов. UXAgent позволяет создавать множество виртуальных пользователей, запускать их в браузере и анализировать как количественные, так и качественные результаты взаимодействия с системой.

Проект использует идеи:

* генерации пользовательских персон;
* браузерного взаимодействия через Playwright;
* симуляции пользовательских действий;
* анализа пользовательских сценариев;
* автоматизированного UX-тестирования.

### Используемый проект

[UXAgent GitHub Repository](https://github.com/neuhai/UXAgent?utm_source=chatgpt.com)

## 🎭 Генерация агентов

Для каждого запуска формируется набор виртуальных пользователей.

Примеры параметров персон:

* возраст;
* уровень технической подготовки;
* опыт использования аналогичных систем;
* цель использования продукта;
* особенности поведения;
* предпочтения при навигации.

---

## 🌐 Выполнение тестирования

Каждый агент:

1. Открывает тестируемый интерфейс.
2. Получает пользовательскую цель.
3. Выполняет действия через браузер.
4. Принимает решения на основе контекста страницы.
5. Формирует обратную связь по результатам взаимодействия.

Для взаимодействия с интерфейсом используется Playwright.

## 📊 Собираемые метрики

### Навигационные метрики

* количество выполненных действий;
* количество переходов;
* успешность прохождения сценария;
* время выполнения задачи;
* количество ошибок.

### UX-метрики

* достижение пользовательской цели;
* сложность выполнения сценария;
* точки отказа пользователей;
* частота проблемных действий;
* субъективная оценка интерфейса агентом.

### A/B-метрики

* конверсия;
* успешность сценариев;
* среднее время выполнения задач;
* количество ошибок;
* статистическая значимость различий между вариантами.

## 📦 Формируемые артефакты

```text
results/ - вердикт по эксперименту (md/json), агрегированные метрики и их интерпретация
heatmaps/ - визуализация действий агентов по страницам (карты кликов и скроллов)
vi_bugs/ - отчеты о визуальных и поведенческих дефектах интерфейса
groups/ - описание групп агентов с ссылками на их идентификаторы и общие данные
agents/ - детализированные дампы выполнения каждого агента (память, шаги, история)
```
